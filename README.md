# 手机采购入账 iPad 手动版

这是不需要 App Store 的 iPad 网页 App。数据保存在当前 iPad；通过“导出数据”和“导入数据”与 Windows 版手动交换。

## 使用方法

1. 解压后，将文件夹内的所有文件上传到 GitHub repository 的根目录（不要再套一层文件夹），再启用 GitHub Pages。
2. 用 iPad 的 Safari 打开网址。
3. 点 Safari 的“分享”按钮，选择“添加到主屏幕”。
4. 以后从主屏幕图标进入。首次加载后，即使没有网络也可以使用。

## 数据迁移

- Windows：点“导出数据”，把 JSON 文件保存到 iCloud Drive、邮件或 AirDrop。
- iPad：点“导入数据”，选择该 JSON 文件。
- iPad 回传 Windows 时操作相反。

导入会替换当前设备的采购记录和管理设置。导入前请先导出当前设备的数据作为备份。
